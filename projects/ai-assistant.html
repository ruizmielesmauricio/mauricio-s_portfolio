01 / THE QUESTION

Start with the problem.

How can a recruiter quickly find relevant evidence across a portfolio, work history and technical projects?

02 / THE PROCESS

From raw data to a useful solution.

Structured background information in Markdown, used embeddings and a vector database to retrieve relevant passages, and connected retrieval to a language model through a Streamlit chat interface.

03 / THE OUTCOME

What the work showed.

Built and deployed a conversational interface for questions about my background. The portfolio loads the assistant only when requested, keeping the main page focused and lightweight.

04 / THE PERSPECTIVE

Interpret the result in context.

Responses can contain mistakes and depend on the source documents and service availability. Project reports and the professional profile remain the primary references.
