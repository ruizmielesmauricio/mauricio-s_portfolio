CASE STUDY / ANALYTICS & DASHBOARDS

Death’s discography, explored

A complete studio-discography explorer built from multiple music APIs and carefully cleaned metadata.

PythonAPIsPlotly
Open live demo ↗View source code ↗Read the report ↗

01 / THE QUESTION

Start with the problem.

How can fans explore the evolution of a band’s studio catalogue without duplicate releases and inconsistent metadata obscuring the story?

02 / THE PROCESS

From raw data to a useful solution.

Integrated Spotify, Last.fm, MusicBrainz and AcousticBrainz data. Applied custom cleaning to exclude compilations and bonus tracks, then created album, tempo, duration and audience comparisons.

03 / THE OUTCOME

What the work showed.

Delivered a Streamlit dashboard covering seven studio albums and 62 tracks, with a release timeline, track rankings, filters and head-to-head album comparisons.

04 / THE PERSPECTIVE

Interpret the result in context.

Audience metrics are source-specific snapshots. Missing metadata and alternative releases require explicit cleaning rules.

MY CONTRIBUTION

Built end to end.

Data collection, release matching, cleaning, interactive visualisation and deployment.
